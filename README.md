# Weblog 博客系统

线上地址：http://ccostore.cyou/

这是一个前后端分离的个人博客系统，包含文章展示、文章详情、评论区、后台管理、数据看板、Markdown 编辑与项目部署等功能。

## 技术栈

- 前端：Vue 3、Pinia、Vue Router、Element Plus、ECharts、md-editor-v3、Axios、Vite
- 后端：ASP.NET Core 8、MySQL
- 部署：Docker、Docker Compose、Nginx / OpenResty

## 功能简介

- 文章列表、文章详情、分类、标签、归档
- 评论区、留言板、日志、知识库
- 后台表单、表格、弹窗、分页等管理页面
- 访问量和文章数据图表展示
- Markdown 编辑与预览
- Docker + Nginx 部署上线
